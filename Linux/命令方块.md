1.
sudo apt update
作用：从远程服务器下载最新的软件包列表到本地，让你知道有哪些软件可以安装或升级。
相当于相当于刷新应用商店的列表，还没点"下载"
2.
sudo apt upgrade
作用：将系统中已安装的软件包升级到最新版本
`update` 是刷新商店列表，`upgrade` 是真正点"更新"按钮。

常见组合：sudo apt update && sudo apt upgrade

&& 这种符号属于shell操作符，具体来说是：- **命令连接符 / 命令控制操作符**（Command Control Operators）

| 符号           | 名称    | 作用             |
| ------------ | ----- | -------------- |
| `&&`         | 逻辑与   | 前成功才执行后        |
| \|\|         | 逻辑或   | 前失败才执行后        |
| `;`          | 命令分隔符 | 顺序执行           |
| \|           | 管道符   | 前一条的输出作为后一条的输入 |
| `&`          | 后台执行符 | 命令放到后台运行       |
| `>` `>>` `<` | 重定向符  | 控制输入输出方向       |
