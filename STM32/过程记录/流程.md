# 添加模块文件
下面涉及添加文件，比如各模块的头文件和源文件的位置
由于用到CMake,这就有点说法了
现在的做法是在根目录加一个user.cmake文件
内容是
```
# 递归扫描 Hardware 下所有子文件夹里的 .c 文件

file(GLOB_RECURSE HARDWARE_SOURCES "Hardware/*/*.c")

# 将源文件追加到主工程目标中（注意：${PROJECT_NAME} 是插件生成的目标名）

target_sources(${PROJECT_NAME} PRIVATE ${HARDWARE_SOURCES})

# 添加头文件搜索路径

target_include_directories(${PROJECT_NAME} PUBLIC Hardware)
```
然后在CmakeList.txt的,add_executable(${CMAKE_PROJECT_NAME})这个位置加上include...,如下
```
add_executable(${CMAKE_PROJECT_NAME})
include(user.cmake OPTIONAL)
```
至于为啥，以后慢慢搞吧
添加完后记得ctrl+p 输入`CMake: Configure`,确定
然后在build/Debug的compile_commands.json这个文件，搜Hardware即可知道配置是否成功

目前.c 文件只需#include "xx/xx.h"即可，如#include "LED/LED.h"
.h文件则是
```
#ifndef __KEY_H
#define __KEY_H

#include "main.h"
  
#endif
```
放在main.c里的头文件也按这个进行include即可
