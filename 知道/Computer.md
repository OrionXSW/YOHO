# PCIe 速查笔记
## 基本概念

| 项目   | 说明                                        |
| ---- | ----------------------------------------- |
| 全称   | Peripheral Component Interconnect Express |
| 本质   | 高速串行点对点**总线标准**（硬件接口 + 分层协议）              |
| 拓扑   | 点对点，非共享总线                                 |
| Lane | 1对差分TX + 1对差分RX（共4根线）                     |
| 捆绑   | ×1 / ×2 / ×4 / ×8 / ×16                   |
| 带宽公式 | 单Lane速率 × Lane数                           |
## 协议分层

| 层     | 职责             |
| ----- | -------------- |
| 事务层   | 组装TLP包（读/写/完成） |
| 数据链路层 | ACK/NAK，保证可靠传输 |
| 物理层   | 编码、电气信号        |

## 各代速率

| 代   | 单Lane速率 | ×1        | ×2      | ×4       | ×16      |
| --- | ------- | --------- | ------- | -------- | -------- |
| 2.0 | 5 GT/s  | ~500 MB/s | ~1 GB/s | ~2 GB/s  | ~8 GB/s  |
| 3.0 | 8 GT/s  | ~1 GB/s   | ~2 GB/s | ~4 GB/s  | ~16 GB/s |
| 4.0 | 16 GT/s | ~2 GB/s   | ~4 GB/s | ~8 GB/s  | ~32 GB/s |
| 5.0 | 32 GT/s | ~4 GB/s   | ~8 GB/s | ~16 GB/s | ~64 GB/s |

## 嵌入式常见用途

| 外设 | 典型接口 |
|------|---------|
| 4G/5G模组 | M.2 / Mini-PCIe |
| NVMe SSD | M.2 (PCIe ×4) |
| 多路摄像头采集卡 | PCIe ×4 / ×8 |
| AI加速卡 | PCIe ×4 / ×16 |
| 万兆网卡 | PCIe ×8 |

> **记忆**：SPI/I2C是乡间小路，PCIe是多车道高速公路。
